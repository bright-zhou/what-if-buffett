# What If Buffett

拖拽柱状图"篡改历史"，实时观察巴菲特 60 年投资生涯的蝴蝶效应。

→ 在线体验：[待部署后填充]

## 这是什么

一个交互式投资模拟器。页面展示了沃伦·巴菲特 1965–2025 年共 61 年的实际投资收益率，你可以**直接拖拽图表中的柱子**来修改某一年的回报率，系统会即时重算后续所有资产变化，让你直观感受复利的力量——以及一个决策如何改变终局。

三条曲线对比：
- **巴菲特实际** — 他的真实回报
- **标普 500** — 同期指数基准
- **你的假设** — 你修改后的"平行宇宙"

## 使用场景

- 理解复利效应："如果巴菲特 1970 年代亏了 50% 会怎样？"
- 感受摩擦成本："每年多扣 2% 的管理费，60 年后差多少？"
- 验证直觉："去掉收益最差的那几年，最终资产能翻多少？"

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173` 即可体验。

## 构建部署

```bash
npm run build   # 输出到 dist/
npm run preview # 本地预览构建结果
```

`dist/` 目录为纯静态文件，可部署到任何静态托管服务（Vercel / GitHub Pages / Netlify 等）。

## 技术栈

React 19 + TypeScript + Vite + Recharts + Vitest

无后端、无数据库、无路由、无状态管理库。纯前端应用，一次构建随处托管。

## 数据来源

Berkshire Hathaway Annual Reports (1965–2025)，巴菲特历年致股东信中的年度收益率数据。
